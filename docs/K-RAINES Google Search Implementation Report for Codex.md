# K-RAINES Google Search / SEO Implementation Report

## 1. Objective

Update the website repository for:

**Production website:** `https://rainesusa.org/`

The goal is to make Google clearly associate the website with the brand:

**Primary brand name:** `K-RAINES`

**Full organization name:** `Korean Robotics & AI New England Society`

The site should have strong, consistent signals so searches such as:

- `K-RAINES`
- `K-Raines`
- `K Raines`
- `Korean Robotics & AI New England Society`
- `Korean Robotics AI New England`
- potentially related searches such as `Korean robotics Boston` or `Korean AI Boston`

can identify `rainesusa.org` as the official website.

This work should improve Google's understanding of the organization and website. It does **not** guarantee a particular ranking position.

# 11. WebSite Structured Data — HIGH PRIORITY

Add or update `WebSite` JSON-LD on the **homepage**.

If an existing `WebSite` JSON-LD object exists, modify that object instead of adding another duplicate object.

Recommended:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "K-RAINES",

    "K-Raines",
    "RAINES",
    "rainesusa.org"
  ],
  "url": "https://rainesusa.org/"
}
</script>
```

The preferred value of `name` must be:

```text
K-RAINES
```

Keep the canonical homepage URL consistent everywhere:

```text
https://rainesusa.org/
```

Do not create multiple competing `WebSite` objects.

```json

]
```

Only use verified official URLs already available in the project or clearly known to be official.

Do not guess.

# 14. Sitemap

Possible location:

```text

```

Do not replace an existing valid sitemap with a one-page sitemap.

Ensure the canonical homepage URL is included:

```xml

</url>
```

If manually creating a minimal sitemap is appropriate for this site's architecture, a valid example is:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://rainesusa.org/</loc>
  </url>
</urlset>
```

All existing indexable pages should remain in the sitemap.

Use fully qualified HTTPS URLs.

Do not add fake or automatically changing `<lastmod>` values.

If `<lastmod>` already exists, retain it only if the project can keep it accurate.

# 15. robots.txt

Inspect the existing `robots.txt`.

The production site must not unintentionally block Google from crawling the homepage.

A simple configuration may resemble:

```text
User-agent: *
Allow: /

Sitemap: https://rainesusa.org/sitemap.xml
```

If the project has intentional crawler restrictions for other areas, preserve them.

Do not replace a sophisticated existing `robots.txt` with the minimal example above.

Instead:

1. make sure `/` is crawlable,
2. make sure there is no accidental site-wide `Disallow: /`,
3. add the sitemap reference if appropriate.

Also inspect the homepage for accidental:

```html
<meta name="robots" content="noindex">
```

or equivalent HTTP/X-Robots-Tag behavior.

The production homepage must not be `noindex`.
