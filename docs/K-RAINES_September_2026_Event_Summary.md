## 8. Questions to Confirm with the Consulate

The following items were identified as useful and appropriately scoped questions for the Consulate.

### A. Meeting room / basic supplies
Ask:
- What facilities and basic supplies are already available in the room?
- What should K-RAINES bring separately?

### B. Presentation equipment
Because Prof. Padir and multiple Lightning Talk speakers will present slides, confirm availability of:
- Projector and/or display
- Screen
- Microphone
- Speakers / audio
- Laptop connection method, especially HDMI
- Any adapters or cables that K-RAINES needs to bring

### C. Guest Wi-Fi
Ask whether:
- Presenters or attendees can use Guest Wi-Fi
- There are any access instructions or limitations

Reason: Some Lightning Talk speakers may want to demonstrate AI Agent workflows live.

### D. Event setup / food
Ask:
- Whether there are any rules for bringing and setting up food
- What time organizers can enter the venue for setup before the 6:00 PM start

### E. Entry / security procedures
Ask whether:
- K-RAINES must submit an attendee list in advance
- There is a deadline for submitting the list
- Attendees need to bring identification
- There are any other building or Consulate entry procedures

This matters because K-RAINES is collecting RSVPs in advance.

### F. Parking
Ask whether:
- There is a recommended parking location for attendees
- The Consulate has any parking validation, parking ticket, or parking support arrangement for visitors

Context: Nearby hotel/building parking can be expensive, and there have apparently been occasions where the Consulate could provide or support nearby hotel parking tickets. Availability for this event is unknown and should be asked rather than assumed.

### G. Raffle / promotional gifts
K-RAINES may run a small raffle to encourage participation.

Ask whether:
- The Consulate has promotional items, souvenirs, or small gifts that could be contributed as raffle prizes, similar to what was available in a previous year
